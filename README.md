# InfoCatcher

AI 工具信息聚合平台 —— 一个开源免费的中文 AI 工具信息聚合与场景化对比项目，帮助用户降低 AI 工具选择的搜索成本与决策错误率。

> 项目状态：可行性研究完成（Conditional Go），MVP v0.1 骨架已就位，开发中。
