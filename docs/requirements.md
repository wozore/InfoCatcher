### 用户痛点 → 需求映射

| 痛点（调查证据） | 衍生需求 |
|---|---|
| 信息分散（Q8 60.7%） | AI 工具库 + 信息聚合 |
| 软文多、真假难辨（Q8 45.5%；仅 10.7% 信任评测） | 可信评测体系 |
| 更新太快、信息过时（Q8 43.8%） | 信息时效性标注 + 更新机制 |
| 宣传与实际不符（51.8% 曾遇） | 场景化真实表现对比 |
| 工具-场景映射缺失（Q18） | 场景化推荐 / 场景导航 |
| 选错工具（63.4% 曾选错） | 多维度对比 |
| 付费焦虑（Q18 均值 3.46/5 最高） | 价格与权益透明化 |

## 功能需求

> 优先级：P0=必须(MVP)，P1=应纳入，P2=后续。
> 标注 `[已实现]` / `[未实现]` 反映当前 MVP 实际状态。

### 工具信息库（FR-CORE）

| 编号 | 需求 | 优先级 | 状态 |
|---|---|---|---|
| FR-CORE-01 | 提供 AI 工具信息库，每条至少包含：名称、厂商、分类、功能描述、价格/权益、免费额度、访问门槛、中文支持、擅长场景、最后更新日期 | P0 | 已实现 |
| FR-CORE-02 | 每个工具标注适用场景标签（写论文/写代码/做PPT/翻译等） | P0 | 已实现 |
| FR-CORE-03 | 每条记录显示"最后更新日期" | P0 | 已实现 |
| FR-CORE-04 | 初始内容覆盖 ≥ 20 个主流 AI 工具（含国产） | P0 | 已实现（当前 45 个） |
| FR-CORE-05 | 支持众包纠错（用户提交 → 审核入库） | P1 | 已实现（GitHub Issue 模板） |
| FR-CORE-06 | 推荐结果优先落到具体模型、产品版本、变体或套餐；泛化品牌/入口作为集合展示已核实子项 | P1 | 已实现 |
| FR-CORE-07 | 高频变化的模型、API价格、套餐与上下文信息保留官方优先来源链接和查询时间 | P1 | 已实现 |
| FR-CORE-08 | LLM 模型按权威资料展示缓存命中/未命中/输出每百万 tokens 价格 | P1 | 已实现 |
| FR-CORE-09 | 集合入口以厂商总览呈现精简说明与可区分特点；采用可追溯层级导航 | P1 | 已实现 |

### 暂不纳入 MVP

| 功能 | 原因 |
|---|---|
| 用户注册/登录系统 | MVP 用 localStorage 即可 |
| 用户评价/UGC 社区 | 冷启动风险高，以 GitHub Issues 作轻量反馈 |
| AI 自动事实裁决/商单定性 | 首版采用规则 + 证据 + 置信度 |
| 运行时 Serverless 采集、数据库、实时推送 | 只做构建时采集和静态 JSON；完整后端留至环 C |

## 范围边界

**In Scope：** AI 工具信息聚合与展示、多维度场景化对比、价格与权益透明化对比、场景化推荐

**Out of Scope：** AI 工具的代理销售/分销、自有 AI 模型的训练、企业内部 AI 部署咨询、LLM/Agent 类 API 的高频调用
