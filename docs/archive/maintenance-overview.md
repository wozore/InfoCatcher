# 软件维护（历史入口）

> Issue 模板和人工审核在 MVP 即启用；AI 初审仍是 v1.0+ 可选能力。当前操作以 [运维文档](../operations.md) 和根目录 [贡献指南](../../CONTRIBUTING.md) 为准。

## 更新流水线

```text
用户通过 GitHub Issue 提交 → 人工审核 → 合并入库
                              ↑
                    AI 初审（v1.0+，尚未实现）
```

| 层 | 职责 | 状态 |
|---|---|:---:|
| 用户提交 | 结构化提交纠错或新工具 | MVP |
| AI 初审 | 检查字段、来源和事实 | v1.0+ 可选 |
| 人工审核 | 维护者最终确认 | MVP |

## Issue 模板

`.github/ISSUE_TEMPLATE/` 必须位于仓库根目录，GitHub 才能识别：

| 模板 | 用途 |
|---|---|
| `data-correction.yml` | 纠错；要求工具、字段、现有/正确信息和来源 |
| `new-tool.yml` | 推荐新工具 |

维护活动分为改正性（纠错）、适应性（环境/API 变化）、完善性（新增功能）和预防性（ToS 监控、时效提示）；当前任务见 [开发计划](../../开发计划.md)。
