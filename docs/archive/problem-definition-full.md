# AI 信息获取与工具选择：问题定义

> **开发目标**：提高用户对 AI 工具的熟悉程度和使用能力。
> 本文包含前期问题假设、**计划版 41 题问卷**和大模型评测方法。实际执行的是另一份 22 题问卷，见 [调查结果](user-survey-full.md)；两版题号和选项不可直接互引。

## 1. 问题与边界

国内用户在发现、理解、比较和选择 AI 工具时面临一组相互关联的问题：

| 根因 | 可观察后果 | 待验证重点 |
|---|---|---|
| 工具、模型、功能和价格更新快 | 教程、价格和推荐迅速过期 | 用户是否注意并因过期信息做错决定 |
| 信息散布在官方、媒体、社区、排行榜和社交平台 | 跨平台搜索成本高、信息冲突 | 获取渠道数量、便利度和完整性 |
| 参数与 Benchmark 难以转成场景结论 | 用户依赖营销、跑分或口碑 | 是否需要通俗、场景化比较 |
| 国内外工具在语言、访问、支付和生态上不同 | “最好”与“可用”不一致 | 访问、中文、价格和限制是否构成硬门槛 |
| 宣传、版本和真实体验有落差 | 试用/付费后失望，信任下降 | 误导经历及评测信任度 |
| 缺少“任务 → 工具”映射 | 用错工具、反复试错或放弃 | 面对具体任务能否快速选择 |
| 信息过载、不可信和滞后叠加 | 分析瘫痪、跟风、低决策信心 | 问题频率、强度和行为后果 |

本阶段只定义和验证问题，不预设用户必然需要某种聚合产品。

## 2. 用户群体假设

以下画像是调查前假设，不是已验证事实：

| 群体 | 主要场景 | 区分性约束/问题 |
|---|---|---|
| AI 新手/普通用户 | 问答、简单文字和探索 | 不懂术语、选择维度和入门路径 |
| 学生 | 学习、论文、翻译、PPT、编程作业 | 预算、免费额度、学术诚信、中文能力 |
| 职场办公人群 | 周报、邮件、会议、数据、PPT | 时间有限、企业网络、隐私和合规 |
| 程序员/开发者 | 编码、调试、文档和架构 | 模型/API 价格、上下文、IDE、开闭源 |
| 内容/视觉创作者 | 文案、图像、视频、音频和分发 | 风格、版权、工作流组合、商用许可 |
| 自媒体/知识博主 | 热点、内容生产和粉丝运营 | 既消费又生产信息，商业立场复杂 |
| 企业管理者 | 采购、部署、培训和 ROI | 企业定价、集成、安全、审计和供应商稳定性 |
| AI 重度用户 | 多模型工作流和持续追踪 | 噪音、细粒度能力、订阅和迁移成本 |

学生、职场、创作者和企业群体的需求不能由同一权重模型概括；后续研究应分别取样。

## 3. 假设地图

原 23 个假设合并为 10 个主题，并保留原编号追溯：

| 主题 | 原假设 | 核心假设 | 严重度初判 |
|---|---|---|:---:|
| 发现与聚合 | H1、H2、H18 | 用户不知道有哪些工具，现有列表分散且浅 | 高 |
| 时效 | H3、H15 | 更新速度使信息迅速失效 | 高 |
| 场景匹配 | H4、H9 | 用户无法把具体任务映射到工具 | 高 |
| 判断与可信度 | H5、H6、H10 | 缺少标准，宣传、商单和极端评价影响判断 | 高 |
| 成本与限制 | H7、H11、H23 | 免费/付费、额度和特殊优惠不透明 | 高/细分 |
| 比较与选择 | H8、H14、H21 | 模型差异不清导致犹豫、选错或放弃 | 高 |
| 理解与本地化 | H13、H16、H17 | 术语、中文资料、访问和支付形成门槛 | 中—高 |
| 版权、隐私和安全 | H12、H19 | 商用与数据边界不清阻碍专业使用 | 中，群体差异大 |
| 多工具工作流 | H20 | 进阶用户缺少组合和优化依据 | 低，待验证 |
| 同类用户参照 | H22 | 用户需要与自己相似人群的真实经验 | 中 |

### 问题链

```text
发现 → 理解 → 判断可信度/时效 → 比较 → 场景匹配 → 使用/付费决策 → 反馈与优化
```

调查应分别测量普遍性、强度、影响和人群差异，避免把“喜欢某个解决方案”误当成问题成立。

## 4. 计划版调查问卷（41 题）

> 这是调查设计稿，不是最终执行问卷。题号映射只能近似建立：实际问卷新增性别题，并删改、合并了多道题与选项。实际 Q2≈计划 Q1（年龄）、实际 Q3≈计划 Q2（职业）、实际 Q5≈计划 Q3（频率）、实际 Q4≈计划 Q4、实际 Q6≈计划 Q5、实际 Q7≈计划 Q8、实际 Q8≈计划 Q16、实际 Q10≈计划 Q14、实际 Q11≈计划 Q17、实际 Q12≈计划 Q22、实际 Q13≈计划 Q21、实际 Q14≈计划 Q24、实际 Q15≈计划 Q28、实际 Q16≈计划 Q25、实际 Q17≈计划 Q27、实际 Q18≈计划 Q31、实际 Q20≈计划 Q33、实际 Q21/Q22≈计划 Q38/Q40。**选项发生变化，不可直接比较。**

### A. 基础情况（Q1—Q7）

1. **年龄**（单选）：18 岁以下、18—24、25—30、31—40、41—50、50 以上。
2. **职业/身份**（单选）：学生、职场、管理者、自由职业、开发者、创作者/设计师、教育科研、待业/求职、其他。
3. **AI 使用频率**（单选）：每天多次、每天 1—2 次、每周、每月、很少、从未。
4. **正在使用的工具**（多选）：主流对话、图像、编程、办公、视频工具、其他或未使用；用于识别认知范围和多工具习惯。
5. **主要使用场景**（多选）：闲聊、学习、办公、编程、内容、设计、影音、搜索整理、翻译、娱乐或基本不用。
6. **AI 工具熟悉度**（1—5）：从“不了解主流工具”到“持续追踪并能按场景推荐”。
7. **付费状态**（单选）：已付费、考虑付费、只用免费、不知道哪些值得付费。

### B. 信息获取（Q8—Q16）

8. **信息渠道**（多选）：社交媒体、熟人、媒体、技术社区、博主视频、搜索、应用商店、社群、官方、工具内推荐或不主动获取。
9. **主动了解频率**（单选）：每天、每周、每月、按需、几乎不主动。
10. **获取便利度**（1—5）：从“不知道从哪看”到“很容易获得所需信息”。
11. **信息量感受**（单选）：过多混乱、较多可应付、合适、偏少、严重不足。
12. **能否跟上更新**（单选）：完全跟不上、较吃力、基本能、轻松、不关注。
13. **是否遇到过时信息**（单选）：经常、偶尔、很少、从未、未注意。
14. **对网上评测的信任**（1—5）：从“认为多数是广告”到“总体可靠”。
15. **宣传后失望经历**（单选）：经常、多次、一两次、从未、未因宣传尝试。
16. **最大困难**（最多 3 项）：无从开始、信息分散、更新快、软文真假、中文不足、太技术、缺相似场景、介绍浅、其他。

### C. 理解与判断（Q17—Q23）

17. **能否理解产品介绍和限制**（单选）：完全、大致、较难、基本不能、很少阅读。
18. **理解的术语**（多选）：上下文、Token、多模态、Prompt、Agent、RAG、LLM、API、推理模型或均不理解。
19. **了解的使用限制**（多选）：次数、文件、联网、中文、上下文、免费/付费、隐私或均不清楚。
20. **是否理解模型差异**（单选）：很了解、大致、只知版本、不知道、不关心。
21. **是否清楚常用工具的擅长/不擅长任务**（单选）：清楚、大致、凭感觉、完全不清楚。
22. **选择时最缺的信息**（最多 3 项）：直接对比、场景案例、真实评价、价格额度、限制、隐私、上手成本、版权、中文、其他。
23. **是否高估或低估能力边界**（单选）：常高估、常低估、两者都有、基本准确、未注意。

### D. 比较与选择（Q24—Q30）

24. **多工具间犹豫**（单选）：经常、偶尔、很少、从不、只用一两个。
25. **选择因素排序**（选前 5）：功能、价格、体验、输出质量、免费额度、中文、口碑、隐私、访问、更新、熟人推荐、厂商信誉。
26. **希望比较的维度**（多选）：同任务质量、速度、价格、中文、限制、平台、特色功能、口碑、场景、隐私、其他。
27. **因不了解差异而选错/错过工具**（单选）：多次、一两次、不确定、没有、基本不换。
28. **面对具体任务能否快速选工具**（单选）：能、大多能、常不确定、基本不能、只有一个工具。
29. **是否跟风选择**（单选）：经常、偶尔、很少、从不。
30. **是否有“想用 AI 但不知道能否解决/用什么”经历**（单选）：经常、偶尔、很少、从未。

### E. 强度与优先级（Q31—Q37）

31. **困扰矩阵**（1—5）：信息分散、更新快、不知工具、看不懂、不知适用任务、评价不可信、宣传落差、价格/限制不透明、不知是否值得付费、缺案例、难选择、中文不足、版权不清。
32. **最头疼的 3 项**：从上述问题中限选。
33. **整体影响**（单选）：阻碍使用、明显降效、有影响、不大、无影响。
34. **偏好的信息帮助**（最多 2 项）：一站式信息、定期横评、用户案例、按需推荐、入门/术语、对比表、同类人群参考、其他。此题接近解决方案，只作方向参考。
35. **愿意投入的成本**（单选）：时间、付费、两者、只要免费且不额外投入、不需要。
36. **是否因信息/选择困难而放弃或延迟使用**（单选）：严重、一定、轻微、没有、与此无关。
37. **最近一次卡点所在环节**（单选）：发现、评估、比较、上手、优化、付费、没有。

### F. 开放题（Q38—Q41）

38. 描述最近一次因不了解工具而困惑或受损的经历。
39. 描述一次宣传很强、实际失望的经历。
40. 用一句话说明获取和选择 AI 工具时最头疼的问题。
41. 分享其他经验、想法或吐槽。

## 5. 验证与后续研究

最值得优先验证：任务—工具映射、信息分散、宣传与体验落差、付费判断和信息时效。多工具组合、完整分类、模型技术细节、版权和中文信息不足可能只对部分群体成立。

建议的判定方式：

- **普遍性**：多选比例、选择困难和渠道数量；
- **强度**：困扰矩阵均值及最头疼项目；
- **影响**：是否降效、选错、放弃或延迟；
- **差异**：按职业、熟悉度和使用频率交叉分析；
- **真实性**：开放题是否用受访者自己的语言重复这些问题；
- **证伪信号**：多数人认为无影响、不愿投入或几乎未遇到。

问卷后应访谈 10—15 人并观察 3—5 个真实任务，把定量、访谈和行为三角验证，再按频率 × 强度 × 影响排序。问题陈述格式：

> [用户群体] 在 [场景] 中需要 [任务]，但受 [障碍] 影响，导致 [后果]；当前以 [替代方案] 应对。

## 6. 大模型/AI 产品评测方法

### 维度框架

不使用单一总分掩盖场景差异：

| 大类 | 子维度 |
|---|---|
| 核心能力 | 语言、推理、知识准确性、创意、指令遵循、长文本、代码 |
| 产品体验 | 响应速度、交互、稳定性、多模态 |
| 可用性 | 中文、访问、平台覆盖、生态集成 |
| 成本与限制 | 免费额度、订阅/API 价格、上下文和文件等限制、性价比 |
| 信任与安全 | 隐私、内容合规、版权/商用 |
| 生态与持续性 | 更新、社区/支持、厂商稳定性、迁移成本 |

不同画像使用不同权重：学生重免费、中文、准确性和长文本；职场重生成、中文、指令、隐私和集成；开发者重代码、推理、API 和上下文；创作者重创意、多模态和版权；企业重安全、稳定、集成和管理；新手重访问、免费和易用。

### 数据与评分

硬指标取自官方资料和可复现实测：速度、价格、额度、上下文、平台覆盖、Benchmark 和更新记录。高频变化数据绑定来源、查询日期、模型/产品版本和条件。

软指标使用统一任务和 1—5 分 Rubric：

- 相同输入、参数和环境；
- 每个维度 10—20 个任务；
- 至少 3 名评测者独立盲评并记录评分者一致性；
- 5 分=完整满足且质量优秀，3 分=基本满足但有明显缺陷，1 分=失败、跑题、严重幻觉或格式错误；
- 保存原始输入、输出、版本、时间和评分理由。

场景测试优先覆盖周报、论文辅助、代码调试、数据分析、文案、邮件、PPT、翻译、学习辅导和长文档问答。每个场景单独呈现，不跨场景平均。

### 呈现与局限

推荐展示能力画像、场景排名和画像匹配，不发布脱离上下文的“最佳模型”总榜。所有结论须标注模型/产品版本和日期，并说明：测试集可能污染、样本有限、评测者有偏差、语言和场景覆盖不全、免费/付费版本不同。

评测分三层维护：

1. 快速层：更新版本、价格、公开 Benchmark 和少量可复现任务；
2. 深度层：重大版本后覆盖完整维度、多人盲评和场景任务；
3. 用户层：持续收集实际案例，用于发现边缘问题和更新任务集。

核心原则：场景化优先、版本可追溯、事实与主观评分分离、承认局限、不同用户使用不同权重。
