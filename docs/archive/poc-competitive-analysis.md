# 竞品分析报告（历史市场快照）

> **日期**：2026-07-18
> **方法**：Tavily Web 搜索 + GitHub 仓库搜索
> **范围**：中文/国际 AI 目录、开源列表、媒体、社交平台和 Benchmark。规模、功能与绝对性判断均具有时效性，使用前须重新核验。

## 竞品类别

| 类别 | 代表 | 历史观察 |
|---|---|---|
| 中文导航站 | 360AI导航、考拉AI导航、AIGC导航等 | 以搜索、分类、简介和推荐为主，深度与透明度不一 |
| 国际目录 | Toolify、Futurepedia、There's An AI For That、TopAI.tools | 工具量大、更新快，但商业化、广告和排名透明度存在差异 |
| 开源列表 | awesome-ai-tools、free-ai-tools 等 | 以 Markdown 列表为主，易贡献但缺完整交互 |
| 评测媒体/博主 | 科技媒体、B站/X/小红书创作者 | 内容深入或及时，但分散，立场和商业关系需核验 |
| Benchmark/官方文档 | LMSYS、Artificial Analysis、厂商文档 | 技术指标或一手事实强，但不直接回答真实场景选择 |

## 历史差异化判断

| 维度 | 竞品常见形态 | InfoCatcher 方向 |
|---|---|---|
| 覆盖 | 数百至数万工具 | 少而精，优先高频工具 |
| 发现 | 功能分类与关键词 | 任务/场景导航 |
| 比较 | 简介、价格或热度 | 多维场景化比较 |
| 可信度 | 方法和排名规则常不公开 | 来源、更新时间、方法和利益声明 |
| 价格 | 展示套餐数字 | 透明权益；价格计算器仍未实现 |
| 治理 | 商业站点或封闭目录 | 开源、人工审核和社区纠错 |

当时观察到的机会是“场景化深度 + 公开方法 + 开源免费”的交集，而不是再做一个大规模目录。该判断与学生样本中的场景信息、评测信任和价格焦虑相符，但不能证明普遍市场需求。

## 风险

- 大型目录可增加比较或评测能力，“竞品都没有”不是持久优势。
- “商业模式决定不会开源”“首个开源 Web 平台”等推断缺乏充分证据。
- 少而精需要持续维护和可复现评测，否则深度优势不能成立。
- 最大未知是用户是否愿意离开已有社交信息流、主动访问并持续回访。
- 竞品数量、功能、广告、开源状态和排名机制在 2026-07-18 后可能已变化。

## 结论

市场并不空白；历史机会主要在信息质量、场景映射和治理透明度。产品应通过真实任务完成率、反馈和回访验证差异化，而不是依赖竞品数量或“唯一/首个”等未经持续核验的主张。
