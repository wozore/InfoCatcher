# AI 信息获取与工具选择调研：调查结果

> **调查时间**：2026-07-11—07-14
> **方式**：微信/QQ 渠道线上问卷，22 题
> **有效样本**：N=112
> 本报告保存执行问卷的统计摘要。它与 [问题定义](problem-definition-full.md) 中的计划版 41 题不是同一问卷，题号不可直接互引。

## 1. 数据、口径与质量

原研究使用问卷 PDF、原始/编码 CSV 和 Python 分析脚本。已脱敏的编码数据、问卷原文和分析脚本可在 [resources/survey/](../../resources/survey/) 获取。原始文本与编码数据按编号核对，未发现重复、越界值或系统性编码错误。

- 单选题分母为该题有效作答数；多选题分母为 N=112，比例之和可超过 100%；
- Q18 为 1—5 分量表；百分比保留一位小数；
- 性别缺失 25 例（22.5%），按已知男女比 45:42 比例插补（13男:12女），补全后男 58、女 54；分析脚本默认使用比例法，原报告行序法（前17男后8女→男62女50）差异约4人；
- 性别补全非观测事实，所有性别比较都不可靠；缺失比例较高（22.5%），两种插补方法结论不同；
- “职业填空”大量为空属于条件字段，非数据缺失。

### 开放题（Q21—Q22）

有效回答分别为 69 和 81 条。人工归纳的高频主题：宣传与体验不符（约 15）、付费困扰（约 14）、不知道选哪个（约 12）、输出质量（约 10）、信息混乱（约 10）、不会上手（约 8）、支付/访问（约 6）、找不到工具（约 5）。这些频次是人工编码近似值，未提供完整编码表，不能作精确比例。

匿名原声包括：“难以直观比较各个 AI 性能，选择付费时试错成本较高”“工具没有说清楚突出表现，只能按同学推荐选择”等。

## 4. 交叉分析

| 比较 | 结果 | 限制 |
|---|---|---|
| 性别 × 选错 | 男 39/62（62.9%），女 32/50（64.0%） | 22.5% 性别是插补值 |
| 频率 × 信息分散 | 每天 M=3.31、4—5分 50.7%；每周 M=3.14/35.7%；偶尔 M=3.00/22.2% | 未做显著性检验，偶尔组 N=9 |
| 职业 × 选错 | 学生 64/97（66.0%）；职场 2/8（25.0%） | 职场 N=8，不可推广 |
| 性别 × Q18 | 多个维度均值有小幅差异 | 插补 + 未检验，不能解释为“探索者/评估者”等人格差异 |

交叉结果只能生成待验证假设，不能宣称因果或显著群体差异。

## 5. 样本内结论

较稳妥的观察：

1. 社交媒体和熟人是主要信息入口，同时样本报告了分散、软文和过时问题；
2. 场景真实表现、直接比较、用户案例和价格权益是主要信息缺口；
3. 选择犹豫、任务匹配不确定和曾选错在样本中常见；
4. 付费判断、真实案例和信息分散的平均困扰较高；
5. 高频用户对信息分散的评分更高，但仍需更大样本和检验；
6. 学生群体适合作为首轮产品假设的验证对象，只因为样本证据最充分，不代表其是最佳市场。

数据**不能**证明：全国或其他职业群体同样需要；用户愿意为服务付费；某产品形态优于现有替代；可信平台存在商业市场；性别存在稳定差异。

| 优先级 | 方向 | 样本内依据 |

| P1 | 工具聚合 | Q7—Q8 的渠道和分散问题 |
| P1 | 价格与权益透明 | Q16、Q18 |
| P1 | 场景导航/推荐 | Q13—Q15 |
| P2 | 更新与订阅 | Q8、Q9、Q19 |

这些是面向学生样本的产品假设，须通过任务测试、5—10 名种子用户、至少 10 条有效反馈及非学生访谈继续验证。
