## 1. 功能概述

在应用内增加一个"定期推荐"视图页面，展示近期推荐的 AI 工具。该推荐由维护者人工精选/编排，按分类组织，控制展示数量和时间范围，帮助用户发现优质工具而不被信息过载淹没。

与 FR-REC-02（行为偏好推断个性化推荐）的区别：本功能是**编辑推荐**（维护者挑选），不需要用户行为数据；FR-REC-02 是**个性化推荐**（基于用户行为推断）。

---

## 2. 功能需求

### 2.1 推荐列表

| 需求 | 说明 |
|------|------|
| 推荐来源 | 维护者在每次更新周期中挑选值得推荐的工具 |
| 展示内容 | 工具名称、推荐理由、分类标签、推荐日期 |
| 分类组织 | 可按分类（对话/AI编程/AI图像等）或场景分组展示 |
| 数量上限 | 最多显示 X 条（建议默认 X=20，可配置） |
| 时间范围 | 只显示最近 Y 天内的推荐（建议默认 Y=30，可配置） |
| 过期提示 | 超过 Y 天的推荐自动移出列表，或标注"已过期" |

### 2.2 页面交互

- 顶部导航新增"定期推荐"按钮，与工具库/场景导航/对比/关于并列
- 默认按推荐日期倒序排列
- 支持分类筛选（仅看某一类别的推荐）
- 点击工具卡片跳转到工具详情

### 2.3 数据格式（方案1 草案）

```json
// data/catalog/recommendations.json
{
  "config": {
    "max_items": 20,
    "max_days": 30,
    "updated_at": "2026-07-20"
  },
  "recommendations": [
    {
      "tool_name": "通义千问",
      "category": "对话",
      "reason": "近期中文能力大幅提升，新增代码解释器功能",
      "recommended_at": "2026-07-18",
      "expires_at": "2026-08-17"
    }
  ]
}
```
