# 该完成的

- 基线配置管理（即每个阶段的数据，代码与文档）

| 工作内容                                   | 主要任务                                     | 输出成果                     |
| ------------------------------------------ | -------------------------------------------- | ---------------------------- |
| **1. 需求获取（Requirement Elicitation）** | 与客户、用户、业务人员沟通，收集需求         | 原始需求记录、访谈记录       |
| **2. 需求分析与整理**                      | 对需求分类、去重、解决冲突，明确系统边界     | 功能需求、非功能需求         |
| **3. 需求建模**                            | 使用 UML、用例图、流程图、数据流图等描述系统 | 用例图、业务流程图、领域模型 |
| **4. 需求验证**                            | 与客户确认需求是否正确、完整、一致           | 需求评审记录                 |
| **5. 编写需求规格说明书（SRS）**           | 将需求形成正式文档，作为开发依据             | 软件需求规格说明书（SRS）    |
