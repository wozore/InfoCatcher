# PoC（Proof of Concept，概念验证）
## PoC 的边界

|    **判断标准**    |       **PoC**        |
| :------------: | :------------------: |
|     目的     |   验证关键技术假设是否成立   |
|    代码质量    |    可以是一次性实验代码    |
|    功能范围    |   只实现验证所需的最小路径   |
|   是否面向用户   |        否         |
| 是否作为正式系统运行 |        否         |
|    主要产出    | 实验结果、证据、限制和可行性结论 |
|   完成后处理    | 丢弃、归档，或者后续重新设计实现 |
