## 1. 功能概述

在应用内增加"AI 概念词典"页面，收录 AI 领域常见术语（热词与冷门概念），提供简明释义与来源参考，帮助用户理解 AI 工具涉及的技术名词，降低认知门槛。

---

## 2. 功能需求

### 2.1 条目内容

| 字段 | 说明 | 必填 |
|:----:|------|:---:|
| 术语名称 | 如"RAG"、"LoRA"、"Token"等 | ✅ |
| 简要释义 | 1-3 句话说明概念 | ✅ |
| 分类标签 | 如"模型架构""训练方法""部署"等 | ✅ |
| 关联概念 | 链接到相关术语 | 可选 |
| 来源参考 | 释义的出处（论文/文档/权威网站链接） | ✅ |
| 适用场景 | 该概念在 AI 工具选择中的实际意义 | 可选 |

### 2.2 页面交互

- 导航新增"AI 概念"按钮，与工具库/场景导航/对比/定期推荐/关于并列
- 按分类分组展示（如：模型架构 / 训练与微调 / 推理与部署 / 多模态 / Agent / 评估与基准）
- 支持搜索（按术语名称/释义关键词）
- 点击条目展开/跳转查看完整释义
- 外部链接标注来源（文末统一展示引用列表）

### 2.3 数据格式（方案1 草案）

```json
// mvp/data/glossary.json
[
  {
    "term": "RAG",
    "full_name": "Retrieval-Augmented Generation",
    "category": "模型架构",
    "summary": "检索增强生成，在大模型生成回答前先从外部知识库检索相关信息，再将检索结果作为上下文输入模型，减少幻觉并提高回答准确性。",
    "related_terms": ["检索增强", "Embedding", "向量数据库"],
    "source": {
      "name": "Lewis et al. 2020",
      "url": "https://arxiv.org/abs/2005.11401"
    },
    "relevance": "影响 AI 工具能否准确回答专业领域问题"
  }
]
```

## 5. 与现有功能的关系

概念词典与其他视图的关系：

```
工具库（展示工具"是什么"）
  │
  ├── 用户看到不懂的术语（如"这个工具支持 RAG"）
  │
  └──→ AI 概念词典（解释"RAG 是什么"）
        │
        └──→ 来源参考（验证释义准确性）

定期推荐（展示"什么值得用"）
概念词典（解释"背后的原理"）
两者互补，降低用户理解门槛。
```
