# Sandbox 沙盒环境

## 用途

本 `sandbox/` 目录用于存放项目中用于测试、原型验证和演示的临时性文件。在这里进行的实验和配置不会影响核心源码目录的结构和运行。

## 目录结构

```
sandbox/
├── README.md            # 本文件：说明沙盒用途与用法
├── config.json          # 演示配置文件
├── settings.yaml        # 示例设置文件
└── scripts/
    └── generate_samples.py  # 样例数据生成脚本
```

## 使用说明

1. 沙盒内的文件可自由创建、修改和删除，不影响项目主体。
2. 在沙盒中验证通过的配置或逻辑，再迁移到正式目录。
3. 沙盒中的演示配置（如 `config.json`）供快速启动和展示使用，不包含生产环境敏感信息。
